# Nexus-Flux · 极简轻量转发与隧道中枢 (`v1.0.0`)

专为小内存云服务器（如 512MB / 1GB 华为云 SG、轻量中转机）深度重构的极简端口转发与加密隧道管理面板。

## ✨ 核心特性与重构亮点

1. **极致轻量（告别 Java + MySQL + Docker 内存黑洞）**
   - 原版 Flux 采用 `Spring Boot (Java) + MySQL 5.7 + Nginx + Docker`，在 512MB 机器上常驻占用 400MB+ 物理内存与 650MB+ Swap。
   - **Nexus-Flux** 采用**零外部 NPM 依赖的纯原生 Node.js 单进程架构 + 内存 O(1) 缓存 + 10秒防抖批量写盘**，主控常驻物理内存仅 **~18–25 MB**，被控端仅 **~12–16 MB**，Swap 占用归零。
2. **移除冗余多用户管理，专注个人/专线中转直控**
   - 彻底剔除原版繁琐的“多用户开车配额/到期续费/用户隧道分配”模块，保留并强化最核心的：**仪表板、转发管理、隧道管理、节点监控、限速管理、网站配置与灾备迁移中心**。
3. **双引擎被控端支持（100% 兼容原版 GOST 节点 + 极简原生 Light 被控）**
   - 完整实现原版 `WebSocket (/system-info)` + `AES-256-GCM` 通信加密 + `/flow/upload` 流量上报协议。
   - 既支持一键安装 **Nexus-Flux 原生轻量被控 (`-m light`)**，也支持直接对接已有的 **原版 Flux GOST (`v1.2.4`)** 节点。
4. **SSH 快捷管理命令 `fl` 与多面板零冲突共存**
   - 内置全局 `fl` 命令，支持一键配置 Caddy HTTPS 域名反代（采用独立 `# BEGIN NEXUS-FLUX` 标记块，与本机 **极简私有探针 (8080)** 及 **NexusGate-Plus (`ng`)** 共享 443 端口零冲突）。
   - 支持一键开启/解除 **「阻止 IP+端口 直接访问面板」**（开启后仅允许通过绑定的 HTTPS 域名访问面板后台，同时自动放行被控节点加密心跳上报，绝不断连）。
5. **一键备份导出与原版 Flux SQL 无损迁移**
   - 支持导出/恢复 `.json` 与 `.zip` 全量备份，并支持直接导入原版 Flux 导出的 `database_backup_*.sql` 文件无损迁移全部节点、隧道与转发规则。

## 🚀 一键安装命令

将本项目文件上传至您的 GitHub 仓库 `mor2026-28/Nexus-flux` 后，在主控服务器上执行：

```bash
curl -fsSL https://raw.githubusercontent.com/mor2026-28/Nexus-flux/main/install.sh -o install.sh && chmod +x install.sh && bash install.sh
```

安装完成后，在 SSH 任意位置输入 `fl` 即可打开交互式管理菜单：

```text
          ✨ 极简轻量转发 · Nexus-Flux 主控管理面板 (fl) ✨          
======================================================
  1. 安装面板 (初始化部署 Nexus-Flux 主控端)
  2. 更新面板 (保留数据无损更新至最新版)
  3. 重启面板服务 / 查看面板实时状态
  4. 面板域名设置 (自动配置 HTTPS 反代 · 多面板零冲突)
  5. 阻止 IP+6366 端口直接访问面板
  6. 允许 IP+6366 端口直接访问面板
  7. 导出备份 (备份主控配置与历史流量数据)
  8. 恢复备份 (从 JSON / ZIP / 原版 Flux SQL 恢复)
  9. 卸载面板 (卸载 Nexus-Flux 主控端)
 10. 卸载本机被控端 (清理本机 GOST / Light 被控服务)
  0. 退出
======================================================
```

# Nexus-Flux (`v1.1.0`)

轻量级端口转发与加密隧道管理面板，支持多节点状态监控、TCP/UDP 端口直转、跨节点多协议加密隧道转发、流量统计与限速控制。

## ✨ 功能特性

1. **核心转发与隧道管理**
   - **端口转发**：支持单节点 TCP/UDP 双栈监听与高速直转，支持多目标地址负载均衡（主备容灾、轮询、随机、IP 哈希）及指定出口网卡或源 IP。
   - **隧道转发**：支持入口节点至出口节点的跨机加密隧道封装（支持 TLS、WSS、WS、TCP、MTLS、QUIC、KCP、gRPC、HTTP2 等协议），支持单向/双向流量计费与自定义倍率。
2. **实时节点监控与协议控制**
   - 实时监控各节点在线状态、CPU 占用、内存占用、实时上下行速率、累计流量与开机时长。
   - 支持按节点独立开启或关闭 **HTTP / TLS / SOCKS** 协议识别与拦截开关。
   - 内置节点到出口、节点到目标地址的端到端 **TCP Ping 链路延迟与丢包率诊断**。
3. **流量统计与限速管理**
   - 仪表板提供总流量概览、24 小时流量趋势曲线图及按隧道分组的转发配置视图。
   - 支持按隧道或单条转发规则绑定 Mbps 级令牌桶限速策略，实时下发并动态生效。
4. **安全防护与灾备中心**
   - 内置登录防爆破限流锁、PBKDF2-SHA256 密码加密存储与全站安全响应头防护。
   - 支持绑定自定义域名（自动配置 Caddy HTTPS 反代）及开启 **「阻止 IP+端口 直接访问面板」** 安全锁。
   - 支持全量配置与流量数据的一键 `.json` / `.zip` 导出备份与导入恢复。

## 🚀 一键安装命令

在主控服务器上以 `root` 权限执行以下命令完成安装：

```bash
curl -fsSL https://raw.githubusercontent.com/mor2026-28/Nexus-flux/main/install.sh -o install.sh && chmod +x install.sh && bash install.sh
```

安装完成后，在 SSH 任意位置输入 `fl` 即可打开管理菜单：

```text
          ✨ Nexus-Flux 主控管理面板 (fl) ✨          
======================================================
  1. 安装面板
  2. 更新面板
  3. 重启面板服务 / 查看面板状态
  4. 面板域名设置 (自动配置 HTTPS 反代)
  5. 阻止 IP+端口 直接访问面板
  6. 允许 IP+端口 直接访问面板
  7. 导出备份 (备份配置与历史数据)
  8. 恢复备份 (从备份文件恢复数据)
  9. 卸载面板
 10. 卸载本机被控端
  0. 退出
======================================================
```
